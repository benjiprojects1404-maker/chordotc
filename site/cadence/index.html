Connect it

One URL, no account. Pick your app.

Claude (web, desktop or phone)

Settings → Connectors → Add custom connector. Name it Cadence and paste the endpoint above. Then just ask about Arc in any chat.

Claude Code

claude mcp add --transport http cadence https://arc-mcp.benjiprojects1404.workers.dev/mcp

Cursor, VS Code and other MCP apps

Add a remote (streamable HTTP) server to the app's MCP config:

{
  "mcpServers": {
    "cadence": { "url": "https://arc-mcp.benjiprojects1404.workers.dev/mcp" }
  }
}

Your own agent

It's plain JSON-RPC over HTTPS. List the tools:

curl -s -X POST https://arc-mcp.benjiprojects1404.workers.dev/mcp \
  -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

Pro tools

Deeper reports an agent pays for itself, a fraction of a cent per call in USDC on Arc. No account, no subscription.

pro_wallet_report$0.005

Every token an address holds with USD estimates and scam flags, wallet or contract (e.g. a Safe), its 20 latest transfers with counterparties, and its open Chord OTC offers.

pro_token_report$0.005

The full code check, plus holders, supply, 24h volume, the top 10 holders by type (burn, pool, contract, wallet), how concentrated it is, and Riptide rug alarms in the last 30 days.

Payment uses x402: the agent signs a USDC authorization for the exact price, Circle settles it on Arc, and the report comes back with the transaction. If the report fails, nothing is charged. Agents with an x402 wallet pay on their own over MCP, or over plain HTTP at /x402/<tool>.
